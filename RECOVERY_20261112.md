## Restore Without Overwriting

1. Verify `SHA256SUMS` in the backup directory.
2. Extract the archive into a new staging directory, not on top of an existing
   installation. Compare any existing files before installing.
3. Install the application as `/mnt/workspace/Subtask_Annotation _Review`.
4. Restore `.credentials/xb4v.yaml` securely from a trusted surviving instance;
   do not publish the key or embed it in prompts or result JSON.
5. Restore the nested reasoning module's `config.ymal` separately if needed.
6. Recreate dependencies from `requirements_verified.txt`, checking CUDA and
   device support. The backup includes the verified Node Linux binary archive.
7. Run the module tests and inspect configured input/output paths before any
   paid calls. Never start two writers against the same experiment directory.

The screening run remains at its original shared path. Recovery does not
automatically resume, restart or overwrite it.
